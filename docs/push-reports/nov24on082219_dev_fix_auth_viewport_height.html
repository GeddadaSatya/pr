1. Root Cause & Technical Fix

The application applies an 80% zoom scale on desktop devices (`@media (min-width: 975px) { html { zoom: 0.8; } }`). Inside a zoomed root, standard CSS `min-h-screen` (100vh) is scaled down to 80% of the physical viewport height (864px on a 1080p monitor), leaving 216px of unstyled white canvas exposed at the bottom.

By applying `md:min-h-[125vh]` (where $100\text{vh} / 0.8 = 125\text{vh}$), the rendered height on screen becomes exactly $125\% \times 0.8 = 100\%$ of the viewport height across all monitor resolutions.
