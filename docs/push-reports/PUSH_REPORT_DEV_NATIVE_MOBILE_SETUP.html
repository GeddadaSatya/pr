1. Executive Rationale: Why Was This Push Required?

The primary directive for the Wealth Command Expense Tracker requires a frictionless team workflow with instant receipt and invoice capture via camera or file upload, while strictly adhering to a ₹0 operating budget.

photo_camera Native Camera Access

Web browser file dialogs are clunky and often trigger memory crashes on mobile. Native Capacitor camera plugins access hardware directly with hardware acceleration.

devices Single Codebase Triple-Deploy

One React / Next.js codebase simultaneously compiles into a Web PWA, an Android APK, and an iOS IPA without duplicating frontend work.

savings Zero Cloud or Tool Cost

Capacitor is 100% open-source under Apache-2.0. There are no paid mobile cloud build services or recurring developer licensing fees required.

Prior commits established the web dashboard and Android project (`android/`). This push finalized the missing half of the mobile equation: the iOS native container (`ios/App`) with proper permissions, launch screens, and Swift bridging.

4. Key Code Implementations & Permissions

4.1 iOS Camera & Photo Library Permission Keys (ios/App/App/Info.plist) XML 
<!-- Camera Permission for Receipt Scanner -->
<key>NSCameraUsageDescription</key>
<string>Allow Wealth Command to access your camera to capture expense receipts and invoices.</string>

<!-- Photo Library Access for Document Upload -->
<key>NSPhotoLibraryUsageDescription</key>
<string>Allow Wealth Command to select receipt images from your photo library.</string>

<!-- Viewport & Status Bar Settings -->
<key>UIViewControllerBasedStatusBarAppearance</key>
<true/>

Why this matters: Without these explicit strings, iOS immediately crashes upon triggering camera access and Apple will automatically reject the application during App Store review.

4.2 Native Lifecycle Coordinator (ios/App/App/AppDelegate.swift) Swift 
import UIKit
import Capacitor

@UIApplicationMain
class AppDelegate: UIResponder, UIApplicationDelegate {
    var window: UIWindow?

    func application(_ application: UIApplication, didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?) -> Bool {
        return true
    }

    func application(_ app: UIApplication, open url: URL, options: [UIApplication.OpenURLOptionsKey: Any] = [:]) -> Bool {
        // Routes deep-links and OAuth callback URLs back into the Capacitor web application
        return ApplicationDelegateProxy.shared.application(app, open: url, options: options)
    }
}

Why this matters: The ApplicationDelegateProxy ensures that OAuth authentication redirects and magic-link tokens from Supabase Auth route seamlessly into the app.
