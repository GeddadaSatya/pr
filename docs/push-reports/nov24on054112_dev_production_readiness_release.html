2. Code & Architecture Breakdown: What Was Introduced?

Data Persistence & Account Scoping (components/context/finance-context.tsx)

+309 / -12 lines

Eliminated data resets on page reloads (F5). All client transactions, payables, and loans are stored using dynamic scoped keys: wt_${user.id}_expenses for authenticated real users and wt_demo_expenses for guest previewers. When a guest or real user reloads, initUserData reads existing data directly from storage before falling back to initial arrays. Dynamic yield calculation ensures real users with zero loans display 0.0% instead of hardcoded demo yields.

Privacy Security Overhaul (components/modals/privacy-unlock-modal.tsx)

Security Fix

Completely removed the hardcoded '1234' backdoor. For authenticated users, unmasking private balances requires their account login password verified securely via supabase.auth.signInWithPassword. Users can optionally toggle to a custom 4-digit PIN mode. For demo guest mode, demo visitors can unmask balances instantly.

Unified Auth Suite & Password Reset Flow (app/login/page.tsx, app/auth/callback/route.ts)

+1,101 lines

Consolidated 5 routes into a singular luxury responsive architecture: Sign In, Forgot Password, Create Account, Accept Invitation, and Set New Password. Added debounced submit handlers to prevent multiple requests, gold CTA buttons (#d4af37), bottom feature pillar alignment, and guaranteed password reset redirection via /auth/callback?next=/reset-password.

Dynamic Greetings & Category Chip Polish (lib/greetings.ts, components/dashboard/command-strip.tsx, expense-notebook-view.tsx)

+272 lines

Introduced over 120+ time-of-day greetings (Morning, Afternoon, Evening, Night) and 100+ rotating financial mottos with a one-click shuffle button in the command strip. Removed the tick mark (✔) from Quick Add expense category chips, indicating selection cleanly through subtle gold border and background highlighting.
